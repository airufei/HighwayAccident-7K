contributions. The root `LICENSE` covers software under AGPL-3.0. Third-party material
retains its existing terms; none of these licenses grants rights to source videos.

No raw videos or frames are included. Public source data should be obtained from
the original providers listed in `DATA_SOURCES.md` and `THIRD_PARTY_NOTICES.md`.
Any access to authorized real recordings remains subject to the actual agreements;
this repository does not promise that the authors can sublicense all such footage.

The public tables contain filename stems, labels, source/split IDs and aggregate
metadata. No identity-recognition task is performed. Before publishing any separate
image/video examples, independently establish source reuse rights and apply the
necessary identifying-region anonymization. Such media are outside this release.

Model weights accompany the AGPL software. Upstream dependencies and original
datasets retain their own notices. This is a multi-component release, not a blanket
MIT relicensing of the assembled training corpus.
