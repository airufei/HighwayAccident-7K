# Environment

- Python 3.10+
- CUDA 12.6, PyTorch 2.7.1, torchvision 0.22.1
- Ultralytics 8.4.112 (training loop is built on its YOLO trainer)
- 2x A100-40GB for the reported runs

Install:

```bash
pip install -r requirements.txt
```
