# Figures

Run `python 05_figures/render_all.py` after numerical reproduction. The scripts
generate numeric plots and diagrams in English and Chinese. Fonts fall back to
installed serif/CJK fonts; exact glyph appearance depends on installed fonts.

Source/threshold/localization plots use archived numeric figure data. The frozen-head
readout plot uses the freshly recomputed metrics. Figure generation does not rerun
models or independently remeasure the archived runtime/localization experiments.
Third-party qualitative image crops and video frames are not included.
